# User Message Project (CRUD API)

**User Message Project** is a RESTful API messenger backend built with Go (Golang) using the Echo web framework and PostgreSQL. The project features full CRUD capabilities for managing user accounts and text-based message exchange between users, securing sensitive user data using password hashing.

---

## 🚀 Tech Stack

* **Programming Language:** Go (Golang)
* **Web Framework:** Echo (v5)
* **Database:** PostgreSQL
* **DB Driver:** pgx (v5)
* **Security:** `bcrypt` for secure password hashing

---

## 🛠 Features

### 👤 User Management (User CRUD)
* **User Registration:** Creates a new user with a randomly generated ID and a hashed password.
* **Profile Lookup:** Fetches public profile details using the user ID.
* **Username Updates:** Allows users to modify their visible name (requires password verification).
* **Account Deletion:** Wipes user profiles along with automatic cascading deletion of all associated messages (`ON DELETE CASCADE`).

### 💬 Messaging System (Messages)
* **Send Message:** Sends text messages from one user to another (validates sender's password).
* **History Log:** Retrieves the conversation history between two specific users with `LIMIT` support, ordered from newest to oldest.
* **Edit Message:** Modifies the content of an existing message by its ID and auto-updates the timestamp to `NOW()`.
* **Delete Message:** Permanently deletes a message from the system using its unique ID.

---

## 🗄 Database Schema

The application automatically provisions two interconnected tables upon startup:

1. **`users`**
   * `id` (INT, Primary Key) — Unique user ID generated by the backend application.
   * `username` (VARCHAR, Unique) — Public display name.
   * `login` (VARCHAR) — Securely hashed password text.

2. **`messages`**
   * `messageId` (SERIAL, Primary Key) — Auto-incrementing identifier for messages.
   * `idUserFrom` (INT, Foreign Key) — Sender's user ID.
   * `idUserTo` (INT, Foreign Key) — Recipient's user ID.
   * `text` (TEXT) — The actual message content.
   * `when_send` (TIMESTAMP) — Date and time stamp of when the message was sent.

## 🛣 API Endpoints

### Users (`/users`)

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `POST` | `/users/createUser` | Register a user (JSON: `name`, `password`) |
| `GET` | `/users/checkProfile/:id` | Fetch user profile by ID |
| `PATCH` | `/users/update_name/:id` | Update display name (JSON: `name`, `password`) |
| `DELETE` | `/users/delete_user/:id` | Delete account (JSON: `password`) |

### Messages (`/messages`)

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `POST` | `/messages/sendMessage` | Send a message (JSON: `idUserFrom`, `passwordUserFrom`, `idUserTo`, `text`) |
| `GET` | `/messages/checkHistory` | Fetch chat logs (JSON: `idUserFrom`, `idUserTo`, `limit`) |
| `PATCH` | `/messages/updateMessage/:messageId` | Edit a sent message (JSON: `idUserFrom`, `passwordUserFrom`, `idUserTo`, `text`) |
| `DELETE` | `/messages/deleteMessage/:messageId` | Delete a single message by ID |

## ⚙️ Getting Started

### 1. Prerequisites
* [Go](https://go.dev) installed (version 1.22 or higher is required due to `math/rand/v2`).
* A running instance of [PostgreSQL](https://postgresql.org).

### 2. Database Configuration
Before booting up the application, ensure that you have created a database named `user_message_db`. Update the Data Source Name (DSN) connection string inside your `main.go` file as needed:
```go
dsn := "postgres://postgres:your_password@localhost:5432/user_message_db?sslmode=disable"
```

### 3. Install Dependencies
```bash
go mod tidy
```

### 4. Run the Server
```bash
go run main.go
```
The server will start listening for requests on local port `:5050` (http://localhost:5050).
